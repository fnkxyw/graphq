## ✨ Почему graphq

- 🖊 **Выглядит как набросок от руки.** Слегка неровные линии, штриховка и рукописный шрифт. Схема смотрится живой, а не как из корпоративной презентации.
- ⚡️ **Нативное приложение.** Открывается мгновенно и не тормозит даже на тысячах фигур.
- 🔗 **Умные стрелки.** Стрелки цепляются к фигурам и двигаются вместе с ними, а на самих стрелках можно писать подписи.
- 🌗 **Светлая и тёмная темы.** Цвета в тёмной теме подбираются автоматически, рисунок остаётся читаемым.
- 🔁 **Совместимость с Excalidraw.** Открывайте свои `.excalidraw`-файлы как есть.
- 🔒 **Всё локально.** Без аккаунтов, облака и телеметрии: файлы лежат у вас на диске.

## 📦 Установка

1. Скачайте **`graphq.dmg`** со страницы [Releases](https://github.com/fnkxyw/graphq/releases/latest).
2. Перетащите **graphq** в папку **Applications**.
3. Запустите из Launchpad или Spotlight.

> [!IMPORTANT]
> При первом запуске macOS может написать, что приложение не удаётся проверить. Это нормально: graphq пока не нотаризован Apple.
> Откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **«Всё равно открыть»**.
> Можно и так, через Терминал:
> ```sh
> xattr -dr com.apple.quarantine /Applications/graphq.app
> ```

## 🎨 Что умеет

| | |
|---|---|
| **Фигуры** | Прямоугольники, эллипсы, ромбы, линии, стрелки, карандаш, текст и картинки |
| **Стрелки** | Прямые, изогнутые и ломаные под прямым углом. Пять видов наконечников, подписи на стрелках |
| **Стиль** | 3 уровня «небрежности», штриховка, сетка или сплошная заливка, пунктир, скругление углов |
| **Карандаш** | Плавные линии переменной толщины, учитывает нажим пера на планшете |
| **Редактирование** | Группы, слои, выравнивание, блокировка, поворот, привязка к сетке и к соседним объектам |
| **Документы** | Вкладки, автосохранение, история версий, полноценный Undo/Redo |
| **Экспорт** | PNG (1×–3×), SVG, PDF, с фоном или без, в светлой или тёмной теме, всё или только выделенное |
| **Импорт** | Файлы `.excalidraw`, картинки через drag & drop или вставку из буфера |

## ⌨️ Горячие клавиши

Клавиши такие же, как в Excalidraw, переучиваться не придётся.

| Инструмент | Клавиша | | Действие | Клавиша |
|---|:---:|---|---|:---:|
| Выделение | `V` | | Отменить / повторить | `⌘Z` / `⇧⌘Z` |
| Прямоугольник | `R` | | Дублировать | `⌘D` |
| Эллипс | `O` | | Сгруппировать | `⌘G` |
| Ромб | `D` | | Показать всё | `⇧1` |
| Стрелка | `A` | | Масштаб 100% | `⌘0` |
| Линия | `L` | | Сетка | `⌘'` |
| Карандаш | `P` | | Экспорт | `⇧⌘E` |
| Текст | `T` | | Копировать как PNG | `⇧⌥⌘C` |
| Ластик | `E` | | Все сочетания | `?` |
| Рука | `H` | | | |

> [!TIP]
> Двойной клик по пустому месту создаёт текст, двойной клик по фигуре или стрелке добавляет подпись.
> `Space` + перетаскивание двигает холст, а `Q` оставляет текущий инструмент активным после рисования.
